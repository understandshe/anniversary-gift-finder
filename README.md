# Anniversary Gift by Year Finder

An embeddable tool by [Understand She](https://www.understandshe.com/) that shows the traditional, modern and gemstone theme for every wedding anniversary (1 to 75 years), with hand-picked gift ideas for each milestone.

**Live tool:** https://understandshe.github.io/anniversary-gift-finder/

## Embed it on your site

Paste this where you want the tool to appear (works on Blogger, WordPress and any HTML page):

```html
<div class="agf-embed"></div>
<script src="https://understandshe.github.io/anniversary-gift-finder/embed.js" async></script>
```

Open on a specific year with `data-year`, for example `<div class="agf-embed" data-year="25"></div>`.

Simple iframe option:

```html
<iframe src="https://understandshe.github.io/anniversary-gift-finder/?embed=1" style="width:100%;height:1100px;border:0" title="Anniversary Gift by Year Finder"></iframe>
```

## Files

- `index.html` - the tool
- `embed.js` - one-line embed script (auto-resizing iframe)
- `data/years.json` - themes and gift picks for each year (edit this to update products)
- `images/` - original theme images for each anniversary year
